# 浮島樂園 Floating Paradise

手機休閒遊戲的網頁版原型。玩家經營一座浮在空中的小樂園：遊客自己來玩設施、付錢；玩家在「試驗場」玩各種小遊戲來開發、測試、升級設施，看著樂園越來越熱鬧。

目標玩家是「來打發時間」的人，每次玩 1～5 分鐘。主要收入預計是激勵廣告和「免廣告」購買。目前先做網頁版驗證玩法，之後用 Capacitor 包成 iOS／Android App。

## 快速開始

需要 Node.js 18 以上。不用安裝任何套件，也沒有建置步驟。

```bash
npm start
```

| 網址 | 內容 |
|---|---|
| http://localhost:5173/park.html | **主遊戲**：浮島樂園 |
| http://localhost:5173/ball.html?level=1 | 單獨試玩「鋼球滑道」的某一關 |
| http://localhost:5173/?level=1 | 單獨試玩「稜光衝刺」的某一關（不加 `level` 是無盡練習模式） |

用手機測試時，手機和電腦要連同一個 Wi-Fi，然後開終端機上顯示的「手機」網址。Windows 第一次可能會跳防火牆詢問，選「允許私人網路」。

## 遊戲結構

```
樂園（主世界）          遊客玩設施 → 🪙 遊客幣（放著也會賺，離線最多累積 8 小時）
   ↕ 下方按鈕切換
試驗場（副世界）        點設施 →  開發（只花遊客幣）
                                  試運轉 = 玩該設施的小遊戲 → 該設施專屬的零件
                                  升級（遊客幣 + 零件）→ 設施變大、載客變多、收費變高
```

- **每座設施對應一款小遊戲**。玩家愛玩哪款就玩哪款；不想玩某款的人，可以用其他零件以 3:1 代替。
- **資源**：遊客幣（通用）加上每座設施各一種零件。
- **明確不做**：體力、命、離線懲罰、設施衰退、轉蛋、付費才能玩的內容。

## 小遊戲通用規則

之後每款小遊戲都照這套做，鋼球滑道是範例。

- **關卡制**：每關 30 秒～2 分鐘，結果只有過關或失敗，另有 1～3 顆星。每關有固定種子，所以同一關每次都一樣。
- **難度**：鋸齒狀。每 5 關一個難關，後面接兩關輕鬆的；同一關失敗 3 次就悄悄降低難度。每一關都必須能不用道具過關。
- **獎勵**：
  - 第一次過關：拿零件（主要獎勵）
  - 重玩已過的關：25%
  - 失敗：25% × 完成進度
  - 每通過 10 關，該設施收費 +5%，只升不降
- **讓難關變簡單的三個來源**：
  - 設施等級給的永久加成
  - 用遊客幣買道具
  - 失敗時看激勵廣告續玩一次

### 小遊戲和樂園的介面

試驗場用 iframe 載入小遊戲頁面，雙方用 `postMessage` 溝通。

- **樂園 → 小遊戲**：用網址參數傳入。
  ```
  ball.html?mode=lab&level=3&shield=1&boost=0&fails=0
  ```
  `shield` 是設施等級加成（Lv 減 1），`boost` 是有沒有買道具，`fails` 是這關已經失敗幾次（用來悄悄降難度）。加成和道具的實際效果由各款小遊戲自己決定，樂園卡片上的說明寫在 `FACS` 的 `buff` 和 `boost`：

  | 小遊戲 | 設施等級加成 | 道具 |
  |---|---|---|
  | 稜光衝刺 | 每級每關多 3 次衝刺 | 開局多 1 顆心 |
  | 鋼球滑道 | 每級開局 +1 護盾 | 開局護盾 |
- **小遊戲 → 樂園**：每打完一關（過關，或失敗後選擇重來或離開）送一次結果。
  ```js
  { type: 'lab:result', level, pass, stars, progress, durationSec, gems, gemsTotal }
  ```
  要關閉時送 `{ type: 'lab:close' }`。
- **中途離開**：樂園按「結束試運轉」時會送 `{ type: 'lab:quit' }`，小遊戲要回報目前這關的失敗結果，再送 `lab:close`。

### 新增一款小遊戲

1. 新增 `xxx.html` 和 `src/xxx.js`，可以照 `ball.html` 的結構做，實作上面的介面。
2. 在 `src/park.js` 的 `FACS` 加一座設施，設定 `levels: true` 和 `src: 'xxx.html'`；在 `RES` 加一種零件。
3. 在 `park.js` 補上這座設施在樂園裡的畫法，可以參考 `drawMarble`。

## 開發小技巧

- **重置樂園存檔**：在瀏覽器主控台執行下面這行，再重新整理。
  ```js
  localStorage.removeItem('park.save2')
  ```
- **除錯**：網址加 `&debug`，鋼球滑道可以在主控台用 `ballDebug` 看狀態；稜光衝刺可以用 `prismDebug` 看狀態、`prismDebug.dash(x, y)` 直接衝刺、`prismDebug.step(秒)` 不靠畫面直接快轉（瀏覽器分頁在背景時也能測）。
- **鋼球滑道試玩捷徑**：網址加 `&shield=99` 給自己很多護盾，方便直接看到關卡後段。
- **鍵盤操作**：鋼球滑道在電腦上可以用左右方向鍵。
- **程式風格**：全部是瀏覽器原生的 ES modules，沒有框架、沒有打包工具。註解和介面文字都是繁體中文。
